帮助与支持 · Support

欢迎来到找渣男帮助中心。当前公开版本：iPhone 游戏 0.5.1。

怎么玩？

选择 9、16、25 或 36 个头像，点击开始。每个人可以连续点击一个或多个头像，再随时把手机交给下一位。普通头像会弹开消失；点中隐藏渣男的人输。游戏没有“换人”按钮。

没有声音？

检查设备音量和静音开关。游戏右上角有声音开关，旁边可选择三种音效。声音只在用户开始游戏或点击后播放。

画面卡住或声音中断？

关闭并重新打开 App，检查 iOS 版本。若问题持续，请描述游戏版本、iPhone 型号及重现步骤，但请勿提交任何个人机密。

提问和报告问题

使用公开问题追踪页面联系我们。提交事项需要 GitHub 账号；也可以查阅其他玩家报告的问题。

提交支持问题 / Report a problem →

请勿公开发送 Apple ID、密码、购买记录、电话号码、地址或其他敏感信息。我们的游戏不需要此类信息。

Support (English)

Pick 9, 16, 25 or 36 heads. Tap one or several heads, then physically hand the phone to the next player whenever you like. There is no turn button. Whoever taps the hidden losing head loses. Use the speaker and sound-style controls at the top if audio is missing. For help, open a support issue without posting personal information.
